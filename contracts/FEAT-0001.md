## Intent
Crear el esqueleto base de Burnbox sobre Java 25 y Spring Boot 4, con verificación modular de Spring Modulith, migraciones Flyway, entorno local en Docker Compose, Clock inyectable y cabeceras base de seguridad.

## User Story
- Como: **Desarrollador**
- Quiero: **inicializar la estructura base verificada del monolito modular**
- Para: **construir las capacidades de negocio sobre cimientos limpios sin deuda técnica**

## Depends On
- Ninguno

## Use Case
**Actor:** Desarrollador
**Goal:** Esqueleto ejecutable con módulos vacíos, base de datos y tooling de verificación

### Main Flow
1. `docker compose up -d` levanta PostgreSQL y Mailpit
2. `./mvnw verify` compila el código sobre Java 25 y ejecuta tests L2 y L6
3. `ApplicationModules.verify()` y ArchUnit confirman las reglas de arquitectura del proyecto
4. La aplicación inicia en puerto 8080 con endpoints de salud en puerto de management separado
5. Petición HTTP a endpoint público retorna cabeceras de seguridad base y página uniforme

### Alternative Flows
- AF-01: Perfil `test` fija el tiempo mediante un `Clock` simulado y desactiva schedulers de fondo
- AF-02: Petición a ruta inexistente retorna página de error genérica sin revelar trazas ni stacktrace
- AF-03: Perfil `demo` configura límites acotados de TTL y creación

## Business Rules
- BR-001: **Todo el tiempo proviene de un bean `Clock` inyectado** — prohibido `Instant.now()`, `LocalDateTime.now()` y `Clock.system*()`
- BR-002: **Fronteras estrictas entre módulos** — ningún módulo accede a datos ni tipos internos de otro módulo (`ApplicationModules.verify()` pasa)
- BR-003: **Persistencia sin JPA/Hibernate** — solo se permite Spring Data JDBC y `JdbcClient`
- BR-004: **Seguridad de vistas** — solo se permite `th:text` con escape contextual; `th:utext` está prohibido por ArchUnit
- BR-005: **Cabeceras HTTP de seguridad base aplicadas globalmente** — `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `frame-ancestors 'none'`, COOP/CORP `same-origin`
- BR-006: **Manejo uniforme de errores** — una única página de error sin exponer trazas técnicas ni stacktraces
- BR-007: **Migraciones Flyway** — el esquema de base de datos se versiona en `src/main/resources/db/migration/`

## Acceptance Criteria
- AC-001: GIVEN Compose iniciado WHEN `docker compose up -d` THEN PostgreSQL y Mailpit responden saludables en menos de 30 segundos
- AC-002: GIVEN código fuente WHEN `./mvnw verify` THEN compilación y tests pasan limpiamente en Java 25
- AC-003: GIVEN proyecto configurado WHEN `ApplicationModules.verify()` y ArchUnit corren THEN pasan sin violaciones de frontera ni dependencias JPA
- AC-004: GIVEN aplicación en ejecución WHEN GET a endpoint público THEN respuesta incluye cabeceras `X-Content-Type-Options: nosniff` y `Referrer-Policy: no-referrer`
- AC-005: GIVEN ruta con error 404 o 500 WHEN cliente HTTP consulta THEN recibe vista de error genérica sin stacktraces ni datos del sistema
- AC-006: GIVEN análisis estático de código WHEN busca `Instant.now` o `LocalDateTime.now` fuera de configuración de Clock THEN encuentra 0 ocurrencias
- AC-007: GIVEN árbol de dependencias WHEN `mvn dependency:tree` THEN no contiene `hibernate-core` ni `spring-boot-starter-data-jpa`
- AC-008: GIVEN perfil de test WHEN contexto de Spring levanta THEN scheduler está desactivado y el tiempo es controlado por el bean Clock
